    参考
    
        
    flowchart.js 语法
    
      
    
      
    
    

    
    
      
    
        
    
          
    节点 9 种
    
          
    
            
    
              
              
    start流程的起点。
    
              
            
    
            
    
              
              
    end流程的终点。
    
              
            
    
            
    
              
              
    operation一个步骤或动作。
    
              
            
    
            
    
              
              
    inputoutput数据的输入或输出。
    
              
            
    
            
    
              
              
    input仅用于输入。
    
              
            
    
            
    
              
              
    output仅用于输出。
    
              
            
    
            
    
              
              
    subroutine嵌套的子流程。
    
              
            
    
            
    
              
              
    condition是 / 否分支。
    
              
            
    
            
    
              
              
    parallel拆分为多条路径。
    
              
            
    
          
    
        
    

        
    
          
    连接
    
          
    st->op1->cond
cond(yes, right)->io
cond(no)->para
para(path1, bottom)->sub1
    
          
    用 -> 串联节点。条件节点使用 yes 或 no；并行节点使用 path1、path2 或 path3。
    

          
    方向
    
          
    leftrighttopbottom
    

          
    文本、链接与状态
    
          
    op=>operation: 第一行
标签的第二行
op=>operation: 文档:>https://example.com[blank]
op=>operation: 步骤|current
    
          
    节点标签可以延续到下一行。用 |state 为其上色，用 :>url 添加链接。
    

          
    流程状态
    
          
    pastcurrentfutureapprovedrejectedinvalid
    

          
    强调路径
    
          
    st@>op1({"stroke":"#E4572E"})
  @>cond({"stroke-width":6})
    
          
    样式行接受任意 Raphael 属性的 JSON。每条路径写一行。
    

          
    注释
    
          
    以 // 或 # 开头的行会在绘制前被 Plotter 移除。flowchart.js 本身没有注释语法。
    
        
    
      
    
    
    

    
    
      节点名只能是一个单词，标签写在冒号之后。
